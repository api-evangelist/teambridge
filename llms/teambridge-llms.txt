# Teambridge

> Teambridge is an AI-native workforce-management platform for frontline teams, covering scheduling, time tracking, instant pay, onboarding, compliance, and payroll. Its External API is a unified Collections API (OpenAPI 3.1.0) over shifts, users, placements, locations, and custom collections, authenticated with OAuth 2.0 client credentials, with HMAC-signed outbound webhooks for real-time change notification.

## API
- [Teambridge External API docs](https://docs.teambridge.com): Redocly-hosted reference for the unified Collections API.
- Base URL: https://open-api.teambridge.com
- Authentication: OAuth 2.0 Client Credentials; token URL https://teambridge.us.auth0.com/oauth/token (scope: write).

## Specs
- [OpenAPI (harvested)](openapi/teambridge-openapi-original.json): OpenAPI 3.1.0, 12 operations across Collections, Documents, Mappings, Utilities.

## Operations
- listCollections — GET /v1/collections
- listFields — GET /v1/collections/{collectionId}/fields
- listRecords — GET /v1/collections/{collectionId}/records (offset pagination: page, size≤50; up to 10 filters)
- getRecord — GET /v1/collections/{collectionId}/records/{recordId}
- createRecord — POST /v1/collections/{collectionId}/records
- updateRecord — PUT /v1/collections/{collectionId}/records/{recordId}
- listMappings / createMapping / updateMapping / deleteMapping — /v1/mappings (link records to Bullhorn, ADP, etc.)
- POST /v1/documents — upload a document (max 100MB)
- GET /v1/timezones — supported timezones

## Events
- [Webhooks](asyncapi/teambridge-webhooks.yml): outbound HTTPS webhooks, HMAC-SHA256 signed (X-Webhook-Signature over {timestamp}.{body}), snake_case event_type (e.g. shift_created, user_updated, location_deleted); event_id for idempotent consumer processing.
